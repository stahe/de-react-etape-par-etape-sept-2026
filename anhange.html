    13. Anhänge

    13.1. Node.js installieren

    [Node.js] kann von nodejs.org heruntergeladen werden: Wählen Sie die LTS-Version (Long-Term Support) 24 oder die Version 22 ab 22.22; dies verlangt [React Router] 8 ([Vite] 8 verlangt nur 20.19). Das Installationsprogramm für [Windows] installiert auch [npm]. Überprüfen Sie die Installation in einer Konsole:

    node --version
npm --version

    Um mehrere Versionen von [Node.js] auf demselben Rechner zu betreiben, können Sie [nvm-windows] (unter [Windows]) oder [nvm] (unter [Linux] und [macOS]) verwenden.

    Für die Beispiele und die Fallstudie ist insgesamt keine Installation von Werkzeugen erforderlich: [Vite], [TypeScript] (und, für den Server, das Werkzeug [nest]) gehören zu den Abhängigkeiten jedes Projekts und werden von [npm install] installiert. Die Skripte in [package.json] ([npm start], [npm run build]) finden sie im Ordner [node_modules]. Um selbst ein neues Projekt zu erstellen, können Sie [npm create vite@latest my-project -- --template react-ts] verwenden, ohne etwas zu installieren.

    13.2. Visual Studio Code installieren

    [Visual Studio Code] kann von code.visualstudio.com heruntergeladen werden. Es bringt JSX und [TypeScript] von Haus aus mit: Code-Vervollständigung, Typprüfung während der Eingabe, Navigation von einer Komponente ([<InputField>]) zu ihrer Definition und Umbenennen einer Prop im gesamten Projekt. Es ist keine Erweiterung erforderlich; Sie können über das Erweiterungsfenster (Strg+Umschalt+X) ESLint (zusammen mit den Regeln [eslint-plugin-react-hooks], die fehlende Abhängigkeiten in [useEffect] und bedingt aufgerufene Hooks markieren) hinzufügen.

    Öffnen Sie ein Projekt über das Menü Datei / Ordner öffnen (zum Beispiel den Ordner [examples-react]) und öffnen Sie darin über das Menü Terminal / Neues Terminal eine Konsole.

    13.3. Die Erweiterung React Developer Tools

    Die Erweiterung React Developer Tools kann aus dem Erweiterungsshop von [Chrome], [Edge] oder [Firefox] installiert werden. Sie fügt den Entwicklerwerkzeugen des Browsers (F12) zwei Tabs hinzu:

    • „Components“: der Komponentenbaum der Seite (nicht der Baum der HTML-Tags) und für jede Komponente ihre Props, ihr Zustand und ihre Hooks ([useState], [useContext] ...) samt ihren Werten sowie die Komponente, die sie gerendert hat;
    • „Profiler“: ein Protokoll, das zeigt, welche Komponenten bei jeder Aktualisierung neu gerendert wurden, warum („Props geändert“, „Hook 2 geändert“ usw.) und wie lange es gedauert hat.

    Sie können dort eine Prop oder einen Zustand ändern und beobachten, wie sich die Seite aktualisiert: eine hervorragende Möglichkeit, zu verstehen, wann und warum eine Komponente neu gerendert wird. Die Option „Highlight updates when components render“ lässt jede neu gerenderte Komponente auf der Seite aufblinken.

    13.4. MySQL mit Laragon installieren

    Der JSON-Server benötigt [MySQL] (oder [MariaDB]). [Laragon] (laragon.org) installiert unter [Windows] eine davon, gebrauchsfertig, zusammen mit dem Administrationswerkzeug [HeidiSQL]. Nach der Installation:

    • Die Schaltfläche „Start All“ startet den [MySQL]-Server auf Port 3306;
    • der Benutzer [root] hat kein Passwort: Dies sind die Standardwerte aus der Datei [.env.example] des Servers;
    • In [HeidiSQL] (Schaltfläche „Database“) führt der Menüpunkt File / Run SQL File das Skript [database/dbrdvmedecins2.sql] aus.

    Unter [Linux] oder [macOS] installieren Sie [MySQL] oder [MariaDB] mit dem Paketmanager des Systems und führen das Skript mit dem Kommandozeilenclient aus: [mysql -u root -p < database/dbrdvmedecins2.sql].

    13.5. curl installieren

    [curl] ist in den [Windows] -Versionen 10 und 11, [macOS] und den meisten [Linux]-Distributionen enthalten. Prüfen Sie seine Version:

    curl --version

    Die in diesem Dokument verwendete Option [--json] ist seit Version 7.82 (2022) verfügbar. Wenn Sie eine ältere Version verwenden, ersetzen Sie [--json @file] with [-H "Content-Type: application/json" -d @file] oder installieren Sie eine aktuelle Version von curl.se.

    Geben Sie für [PowerShell] [curl.exe] ein, nicht [curl]: In [PowerShell] ist [curl] ein Alias für einen anderen Befehl ([Invoke-WebRequest]), der die Optionen von [curl] nicht enthält. Die Eingabeaufforderung ([cmd]) hat dieses Problem nicht.
